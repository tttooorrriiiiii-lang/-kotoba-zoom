# ことばズーム v10.11

抽象化・具体化を「辞書の一本道」ではなく、観点を切り替えながら練習する思考トレーニング版。

## v10.11 の主な変更

- Wikidataは固有名詞の **正体判定だけ** に限定。Wikidata内部のクラス階層へ潜らない。
- 個人名・ペット名がWikidataに無くても **人 / 犬 / 猫 / 動物 / 場所 / 作品 / 組織** を自分で選んで一般概念へ合流できる。
- 「総理大臣」など普通の言葉は WordNet / 思考ルートを優先。
- 分類の頂上に来たら **意味へ / メタ化** に切り替え可能。例：生物 → 生命 → 生きること → 存在、または 生物 → 生物という概念 → 概念 → 知識。
- 具体化では **種類 / 実例・個体 / 場面 / 五感 / 瞬間** の5方向を選べる。場面・五感などは自由入力で自分の言葉にする。
- ↓具体化の候補一覧では、抽象化で実際に通った言葉を最優先で表示。意味IDごと正確に戻れる。
- 思考の足あとから過去地点へ戻っても、以前のルートを保持。

## デプロイ

6ファイルをリポジトリ直下へ置いて Vercel でデプロイ。`npm run build` が Japanese WordNet の静的 shard を生成します。


## v10.10 TEST LAB
- 48語の固定回帰テストをブラウザ内で実行
- 各段で候補一覧の「一番上」だけを自動選択
- ↑最大7段 + ↓最大3段の来た道チェック
- ループ、同義語往復、Wikidata内部語、既知の意味飛び、途中の正体再判定、戻り失敗をFAIL/WARNで抽出
- 怪しい結果だけコピー可能


## v10.10 fixes
- 固有名詞の正体判定は開始語だけ。途中の一般語でWikidata/正体判定へ戻らない。
- CORE/GUIDED/観点の確認済みルートをWordNetより優先。犬→密偵など既知の別義事故を防止。
- 犬→哺乳類→動物→生物、人間→動物→生物など安全アンカーを追加。
- Wikidata内部語・辞書内部語を候補から強く除外。
- TEST LABを53語に拡張し、固有名詞も候補1位だけで回帰テスト。


## v10.10 test reliability fixes
- WordNet OFF のときは回帰テストを中止（誤PASS防止）
- 重要語は最初の1段も検証。ハチ公→人間のような誤ルートをPASSにしない
- 固有名詞・感情語・動詞・家/指/ジュースなど主要ケースの1段目期待値を追加


## v10.11 追加修正
- `自由` は WordNet の別義へ直行せず、状態 / 可能性 / 権利 / 感覚の観点を先に選ぶ。
- `エモい` は人名扱いせず、感情 / 雰囲気 / 記憶 / 評価へ分岐。
- `やばい / だるい / すごい` など口語形容表現も観点分岐を追加。
- `概念` は 知識 / 言葉 / 文化 のどの視点で見るかを選択。
- `知識` の先は 認知 / 情報 / 共有知 / 知識体系 に分岐して継続できる。
- WordNetの頂上語・観点分岐語では辞書ルートを無理に混ぜない。
- 辞書にない短い日本語を自動で「人」と判定しない。候補がない時だけ「名前・固有名詞として見る」入口を表示し、その後に人 / 犬 / 猫 / 場所 / 作品 / 組織などを選ぶ。
- TEST LAB に 自由 / 知識 / 概念 / エモい / やばい / だるい / すごい を追加。
- 思考ルート / 観点分岐でも、足あとにある語へ自動で再突入しないよう再訪フィルターを追加。戻る操作だけは例外として許可。
