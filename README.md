# ことばズーム v10.21

## v10.21 の主な変更

- **具象化の終点に「🌍 リアル体験まで降ろす」入力欄を追加。**
- いまの具体語に、状態・時間・場所・自分との関係を足して、最後のノードを「自分の体験を含んだひとまとまりの言葉」として作れる。
- 例：`スターバックスラテ` ＋ `少し冷めてた` → **`少し冷めてたスターバックスラテ`**。
- 例：`傘` ＋ `雨の日に駅へ置き忘れた` → **`雨の日に駅へ置き忘れた傘`**。
- 入力中は完成形をライブプレビューし、Enterまたは「この体験語を最後のノードにする」で思考の足あとへ追加。
- リアル体験ノードには `リアル体験 · 体験語 · 下へ` と記録し、前段の semanticType も引き継ぐ。
- 抽象化画面ではこの入力欄を表示せず、具象化時だけ表示する。

## 今回の確認

- `少し冷めてた` + `スターバックスラテ` → `少し冷めてたスターバックスラテ`
- `朝に飲んだ` + `カフェラテ` → `朝に飲んだカフェラテ`
- すでに基語を含む入力は二重連結しない
- JavaScript構文チェック

# ことばズーム v10.19

抽象化・具体化を「辞書の一本道」ではなく、観点を選びながら練習する思考トレーニング版。

## v10.19 の主な変更

- **意味カテゴリの継承**を追加。複合語から中心語へ移ったあとも、`artifact / beverage / place / action / work` などの意味カテゴリを次の段へ持ち越す。
- `公衆電話 → 電話 → 通信機器 → 機器 → 人工物 → 物` のように、中心語へ戻ったあと別義へ乗り換えにくくした。
- 電話・カメラ・スマートフォン・乗り物・病院/学校/美術館・衣類・飲食物など、事故が出やすい中心語に意味アンカーを追加。
- WordNet の sense 選択を、語形だけでなく **前段から継承した意味カテゴリ**でも再スコア。意味カテゴリと強く食い違う親語は候補順位を下げ、必要ならその上位へスキップする。
- 人物判定をさらに厳格化。WordNetで一般語として読める語、意味ヒントが強い語、1文字語などは自動で `人間` にしない。Wikidata人物候補も職業情報などの追加根拠がある時だけ自動合流。
- サ変名詞の共通判定を追加。`退院 / 通院 / 就職 / 退職 / 予約 / 購入 / 研究 / 分析 / 設計 / 実装 / 判断 / 分類` などは、人名より `行為・活動` を優先。
- 芸術語の共通判定を追加。`キュビスム / シュルレアリスム / バウハウス / ポップアート` は `美術運動`、`浮世絵` などは `表現` を優先。
- **内部語フィルタのバグ修正**。これまで `感 / 事 / 質` を正規表現で部分一致していたため、`感情 / 出来事 / 性質` まで誤って内部語扱いし得た問題を修正。1文字語は完全一致だけで弾く。
- `自転車` を誤って `車` に縮めるなど、中心語の削りすぎを抑制。
- TEST LAB の固定語を **180語**へ拡張。電話系、カメラ系、施設、乗り物、衣類、修飾句、サ変名詞、芸術語を追加。

## 今回確認した代表ルート

- 公衆電話 → 電話 → 通信機器 → 機器 → 人工物 → 物 → 存在
- デジタルカメラ → カメラ → 撮影機器 → 機器 → 人工物 → 物 → 存在
- 大学病院 → 病院 → 医療施設 → 施設 → 場所 → 空間
- 電動自転車 → 自転車 → 乗り物 → 人工物 → 物 → 存在
- 赤いシャツ → シャツ → 衣類 → 身につけるもの → 人工物 → 物 → 存在
- 冷めたスープ → スープ → 食べ物 → 食品 → 物 → 存在
- ミルクティー → 飲み物 → 飲料 → 食品 → 物 → 存在
- かわいい → 好ましさ → 評価 → 判断 → 心の働き
- 印象派 → 美術運動 → 芸術運動 → 文化活動 → 文化

# ことばズーム v10.17

抽象化・具体化を「辞書の一本道」ではなく、観点を選びながら練習する思考トレーニング版。


## v10.17 の主な変更

- 「修飾語＋中心名詞」を先にほどくルールを追加。`冷めたコーヒー → コーヒー`、`赤い靴 → 靴`、`古い家 → 家` などを候補1位に。
- 作品タイトルを自由フレーズより先に判定。既知タイトルは即 `作品` へ、`○○の○○` 型はWikidataの作品判定も先に確認。
- `キャンバス / オムニバス / エアバス` が `バス` に誤爆しないよう、`〜バス` 判定を交通語のみに限定。
- `わからない / 知らない / 行かない / 泣いている / 笑ってる` など活用語を固有名詞扱いしにくくした。
- `期 / 患 / 事 / 感 / 質` など一文字の辞書ラベルを表示候補から除外し、TEST LABでもFAIL検出。
- 回帰ルートを追加：`入院 → 病院で療養すること → 療養 → 治療 → 医療`、`癌 → 悪性腫瘍 → 腫瘍 → 病気`、`花柄 → 模様`、`積木 → 積み木 → 玩具`、`瞬間 → ごく短い時間 → 時間`。
- TEST LAB の語彙を大幅追加。作品名、修飾句、活用語、バス末尾誤爆、医療語、多義語を重点回帰。

## v10.15 の主な変更

- `ポスター` は **印刷物 / 告知 / グラフィックデザイン / 掲示物** に分岐し、`掲示 → 交通` の意味飛びを防止。
- `楽しい` は **喜び / 良い体験 / 好ましさ / 快** に分岐し、古語 `倖` を表示禁止。
- `アート` は **創造物 / 表現 / 文化活動 / 美的体験 / 解釈** に分岐。制作物ルート自体は正しい枝として残す。
- `高速バス` は **バス / 移動手段 / 公共交通** に分岐し、場所判定へ誤爆しない。
- `非常階段` は **階段 / 避難経路 / 移動経路** に分岐し、人名判定へ誤爆しない。
- `ミラクル` は **奇跡的な出来事 / まれなこと / 奇跡 / 驚き** に分岐し、いきなり `事` へ飛ばない。
- `趣味` は **興味 / 余暇活動 / 楽しみ / 好み** に分岐。`興味 → 関心 → 心の状態` に整理。
- `靴下` は **衣類 / 編み物製品 / 足を覆うもの** に分岐。`莫大小 / 下足` など古い・ズレた辞書語を表示禁止。
- 複合一般名詞の簡易カテゴリ判定を追加。`〜バス / 〜階段 / 〜駅 / 〜店 / 〜道路` などを固有名詞判定より先に一般カテゴリへつなぐ。
- TEST LAB に上記の回帰語を追加し、既知の事故語を FAIL 条件へ追加。

## 代表的な期待ルート

- ポスター → 印刷物 → 制作物 → 人工物
- 楽しい → 喜び → 感情 → 心の状態
- アート → 創造物 → 人工物 / 表現 / 文化活動 / 美的体験 / 解釈
- 高速バス → バス → 乗り物 → 人工物
- 非常階段 → 階段 → 建物の一部 → 人工物
- ミラクル → 奇跡的な出来事 → 出来事 → 現象
- 趣味 → 興味 → 関心 → 心の状態
- 靴下 → 衣類 → 身につけるもの → 人工物
