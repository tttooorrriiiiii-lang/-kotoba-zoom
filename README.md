# ことばズーム v10.5

WordNet を骨組みにしつつ、人間向けの「抽象化トレーニング」に寄せた版です。

## v10.5 の変更

- 名詞・動詞・形容詞をまとめて対応
- WordNet の synset（意味ID）を固定して、途中で別の意味へ飛びにくくした
- 「営造 → 建物」「アーチファクト → 人工物」など、古い・専門的な表示語を自然な現代語へ置換
- 「実体 / 抽象的実体 / 一統」など、思考練習に不要な辞書ルートは隠す
- 動詞に自然な橋渡しを追加（例：走る → 移動する → 動く → 行動する → 行為）
- 形容詞・多義語に「観点分岐」を追加（例：面白い → 感情 / 性質 / 評価）
- 家なども観点分岐（構造 / 用途 / 人との関係）
- ↓具体化で「来た道に戻る」を最優先表示
- 右側の「思考の足あと」をクリックすると、その時の意味IDごと戻れる
- 戻った途中から別の枝へ進むと、その地点から新しいルートを作れる
- ConceptNet は WordNet / 思考ルートで候補がない時だけ補助
- 自由入力は常に利用可能
