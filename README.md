# ことばズーム v10.13

抽象化・具体化を「辞書の一本道」ではなく、観点を選びながら練習する思考トレーニング版。

## v10.13 の主な変更

- `疲れた` などの活用表現を **固有名詞扱いしない**。名前判定は最後の手段に限定。
- `疲れた` は **疲労 / 身体的疲労 / 精神的疲労 / 消耗** の観点へ分岐。
- `レース` は **競走 / レース生地 / 装飾** を最初に選択。`栲` など古い・難解な辞書語は表示しない。
- `はし / あめ / かみ` など多義語にも意味分岐を追加。
- **メタ化は1ルートにつき1回まで**。一度 `○○という概念` に入ったら、さらに別の `○○という概念` へ自動で連鎖しない。
- `存在 / 可能性 / 心の働き / 概念 / 知識` など抽象度の高い地点では、候補1位を **「ここで一旦頂上」** にして自動上昇を止める。
- メタ化は候補の下側に置き、必要なときだけユーザーが選ぶ。
- `知識 → 認知 → 心の働き → …` のような自動一本道を止め、知識・概念は分岐として扱う。
- ↓具体化では、これまで通った言葉を最優先で表示し、意味IDごと元の道へ戻れる。
- TEST LAB に `疲れた / レース / はし / あめ / かみ` を追加。

## 代表的な期待ルート

- 疲れた → 疲労 → 心身の状態 → 状態 → ここで一旦頂上
- レース → 競走 → 競技 → 活動
- レース → レース生地 → 布地 → 織物 → 繊維製品 → 人工物
- はし → 橋 / 箸 / 端
- あめ → 雨 / 飴
- かみ → 紙 / 髪 / 神
- 生物 → 生命 → 生きること → 存在 → ここで一旦頂上
- 存在 → （必要なら手動で）存在という概念 → 概念 → ここで一旦頂上

## デプロイ

このフォルダの6ファイルをリポジトリ直下へ置いて Vercel でデプロイします。
`npm run build` が Japanese WordNet の静的 shard を生成します。

## TEST LAB

ブラウザの `🧪 TEST LAB` から固定回帰テストを実行できます。

- 各段で候補一覧の **一番上だけ** を自動選択
- ↑最大7段
- ↓最大3段の来た道チェック
- 意味飛び、ループ、古い辞書語、Wikidata内部語、途中の正体再判定を検出
- 「ここで一旦頂上」が1位なら、そこで正常終了


## v10.13 fixes
- 「幻」は見える像 / 想像 / 虚像 / 比喩の意味分岐を先に表示し、`幻 → 間違い` を防止。
- 「電源」は装置 / 電力供給に分岐し、`電源 → 工率 → 物理現象` を防止。`工率` は表示禁止。
- 「飲みかけのコーヒー」など自由フレーズは、いきなり頂上・メタ化せず、痕跡 / 途中 / 日常 / 種類へ分岐。
- 回帰語に 幻 / 電源 / 飲みかけのコーヒー / 飲みかけの私のコーヒーカップ を追加。
